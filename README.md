# ใครคือฆาตกร? — ให้ AI 3 ค่ายเล่นเกมหาคนร้ายบนสถานีอวกาศเป็นภาษาไทย

เกมจาก **[คลิปของช่อง VreKi_]({{CLIP_URL}})** · ช่อง [VreKi_](https://www.youtube.com/@VreKi_018)

เกมหาคนร้ายบนสถานีอวกาศ ผู้เล่น 6 คนเป็น AI ทั้งหมด · มีคนร้ายซ่อนอยู่ 1 คน · ลูกเรือเดินทำภารกิจ คนร้ายแอบลงมือ · พอมีคนเจอศพหรือกดปุ่มประชุม ทุกคนเข้าห้องประชุม คุยกันเป็นภาษาไทยแล้วโหวตคนที่สงสัยออก · เรานั่งดูอย่างเดียว (ไม่มีที่นั่งให้คนเล่น)

## เล่นอะไรได้บ้าง

| แบบ | เป็นยังไง |
|---|---|
| เกม 1 · ธรรมดา | กติกาเดียวกับเกมแรกในคลิป |
| เกม 2 · บทบาทพิเศษ | เพิ่มบท กัปตัน · ช่างซ่อม · ตัวตลก · สัปเหร่อ · คนร้ายได้ท่า **ม่านเงา** ทำให้ทุกคนกลายเป็นเงาดำ จำหน้าใครไม่ได้ · กติกาเดียวกับเกมที่สองในคลิป |
| โหมดทดสอบ | บอทเล่นแทน AI · ไม่เรียก AI · ไม่เสียโควต้า · เอาไว้ลองว่าเกมเปิดได้ |
| เกมย้อนหลัง | 2 เกมจากคลิปพร้อมเสียง ดูได้ทันทีไม่ต้องมี AI · เกมที่เราเล่นเองก็กลับมาดูได้ |

- **เลือกค่าย AI ได้ทุกแบบ** — Claude · ChatGPT · Gemini ค่ายเดียว สองค่าย หรือครบสามค่าย (ที่นั่ง 6 ที่แบ่งเท่าๆ กัน แล้วสุ่มว่าใครได้ตัวละครไหน)
- **ดูสด** — AI คิดอยู่ตาไหน หน้าจอขึ้นว่า "รอ AI คิดตาถัดไป…" · ประชุมจะเริ่มเมื่อ AI คุยจบและเสียงพร้อมแล้ว
- **เสียงพากย์ 3 แบบ** — ปิดเสียง · เสียงฟรี (ไม่ต้องมีคีย์) · เสียง Gemini (เสียงดีกว่า ต้องมีคีย์ Gemini)

## ต้องมีอะไรบ้าง

- **Windows 10 / 11**
- **AI อย่างน้อย 1 ค่าย**
  - Claude → แพ็ก **Claude Pro** ขึ้นไป + โปรแกรม **Claude Code** ที่ล็อกอินแล้ว
  - ChatGPT → แพ็ก **ChatGPT Plus** ขึ้นไป + โปรแกรม **Codex** ที่ล็อกอินแล้ว
  - Gemini → **คีย์ API** จาก [Google AI Studio](https://aistudio.google.com/) (ไม่บังคับ)
- **Node.js 18 ขึ้นไป** (ตัวเกม)
- **Python 3.10 ขึ้นไป** (เฉพาะเสียงพากย์) · **ffmpeg** (เฉพาะเสียง Gemini)

ไม่ต้องลงเองทีละตัว — ให้ AI ของเราติดตั้งให้ (ดูหัวข้อ "ติดตั้ง")

### เรื่องโควต้า อ่านก่อนเล่น

- 1 เกมเรียก AI รวมราว **93–125 ครั้ง** (6 ที่ · ราว 15–25 ครั้งต่อที่) — นับจาก 2 เกมในคลิป · **ราว 3 เท่าของเกมหมาป่า** ที่เคยแจก · ทุกครั้งใช้โควต้าแพ็กของเรา
- **มีแพ็กเดียวแล้วให้ค่ายเดียวเล่นครบ 6 ที่ อาจหมดโควต้า 5 ชั่วโมงก่อนจบเกม** (ค่าประมาณ ยังไม่ได้วัดจริง) · รุ่นใหญ่อย่าง Opus กินโควต้าเร็ว
- ถ้าโควต้าหมดกลางเกม เกมจะหยุดและขึ้นการ์ดบอกว่าค่ายไหนหมดโควต้า (ไม่ค้างเงียบ)
- อยากเล่นได้นานขึ้น: **ผสมหลายค่าย** ให้แบ่งกัน หรือเปลี่ยนเป็น **รุ่นเล็ก / ระดับคิดต่ำ** ในการ์ดตั้งค่า
- ตัวเลขดอลลาร์ของ Claude ที่เห็นในไฟล์เกม = **ราคาเทียบ API ไม่ใช่เงินที่จ่ายจริง** (เล่นผ่านแพ็ก จ่ายแค่ค่าแพ็กรายเดือน)
- Gemini ใช้คีย์ API: คีย์แบบจ่ายเงินตกราว **0.13–0.16 ดอลลาร์ ต่อ 2 ที่ ต่อเกม** (เงินจริง · ค่าประมาณจากเกมในคลิป)
- **เสียง Gemini** ใช้คีย์เดียวกัน: คีย์แบบจ่ายเงินเสียเงินจริงทุกบรรทัดที่พากย์ · **เสียงฟรีไม่เสียเงิน**

## ติดตั้ง

1. กดปุ่ม **Code → Download ZIP** ด้านบนหน้านี้ (หรือโหลดจากหน้า Releases) แล้วแตกไฟล์ไว้สักที่
2. เปิด Claude Code หรือ Codex ในโฟลเดอร์นี้ แล้วพิมพ์ว่า: อ่าน INSTALL-FOR-AI.md แล้วติดตั้งเกมนี้ให้หน่อย

   ```
   อ่าน INSTALL-FOR-AI.md แล้วติดตั้งเกมนี้ให้หน่อย
   ```

AI จะเช็คว่าเครื่องขาดอะไร ถามเราก่อนติดตั้งของที่ขาด ทดสอบเกมในโหมดทดสอบ (ไม่เสียโควต้า) แล้วสร้างไอคอน **ใครคือฆาตกร** บนเดสก์ท็อปให้

ถ้าดับเบิลคลิกแล้ว Windows ขึ้นหน้าเตือนความปลอดภัย (เพราะไฟล์มาจาก ZIP ที่โหลดจากเน็ต) ให้ AI ปลดบล็อกไฟล์ให้ตามขั้นแรกใน `INSTALL-FOR-AI.md` หรือกด **More info → Run anyway**

## เปิด / ปิดเกม

- **เปิด:** ดับเบิลคลิกไอคอน **ใครคือฆาตกร** บนเดสก์ท็อป (หรือ `start.bat` ในโฟลเดอร์เกม) → จะมีหน้าต่างดำเปิดค้างไว้ + เบราว์เซอร์เปิดหน้าแรกของเกมให้
- **ปิด:** กด **ปิดเกม** ที่หน้าแรก หรือปิดหน้าต่างดำ
- **ปิดแท็บเบราว์เซอร์ไม่ได้หยุดเกม** — เกมยังเรียก AI ต่อ (ใช้โควต้า) · อยากหยุดให้กด **หยุดเกม** (มุมขวาบนของหน้าดูเกม หรือที่หน้าแรก) หรือปิดหน้าต่างดำเพื่อปิดเกมทั้งหมด
- เปิดซ้ำตอนเกมเปิดอยู่แล้ว = แค่เปิดหน้าเว็บของเกมเดิม
- กดเริ่มเกมตอนมีเกมเล่นอยู่ หน้าแรกจะถามก่อนว่าจะ **หยุดเกมเดิมแล้วเริ่มใหม่** ไหม

## ตั้งค่า AI และเสียง

ที่หน้าแรกกด **ตั้งค่า AI และเสียง**

- ติ๊กค่ายที่จะให้เล่น · ค่ายที่ยังไม่พร้อมจะบอกว่าขาดอะไร
- **รุ่น** — ค่าเริ่มเหมือนในคลิป (`claude-opus-5-5` · `gpt-6.1-sol` · `gemini-4-argon`) แก้เป็นรุ่นอื่นได้ · **ระดับคิด** ค่าเริ่ม `medium`
- **ทดสอบ** — เรียก AI สั้นๆ 1 ครั้งเพื่อเช็คว่าใช้ได้ (ใช้โควต้า 1 ครั้ง)
- **คีย์ Gemini** — วางแล้วกดบันทึก · คีย์เก็บในเครื่องเราเท่านั้น (`data/gemini_key.txt`) ไม่ถูกส่งไปไหนนอกจาก Google
- **เสียงพากย์** — เสียง Gemini มีปัญหาบรรทัดไหน เกมจะใช้เสียงฟรีแทนบรรทัดนั้น

**คีย์ Gemini แบบฟรี:** โควต้ารายวันต่ำ และอาจใช้รุ่น `gemini-4-argon` หรือเสียง Gemini ไม่ได้ · ถ้าทดสอบไม่ผ่านให้ลองเปลี่ยนเป็นรุ่นตระกูล Flash · Google อาจเอาข้อมูลจากคีย์ฟรีไปพัฒนาโมเดล

## แก้ปัญหา

| เห็นข้อความ | ทำยังไง |
|---|---|
| ยังไม่ได้ติดตั้ง Claude Code / Codex | ให้ AI ติดตั้งตาม `INSTALL-FOR-AI.md` |
| ยังไม่ได้ล็อกอิน Claude Code | เปิด terminal พิมพ์ `claude` แล้วล็อกอินด้วยแพ็กของเรา |
| ยังไม่ได้ล็อกอิน Codex | เปิด terminal พิมพ์ `codex login` |
| Claude Code เวอร์ชันเก่าเกินไป | เปิด terminal พิมพ์ `claude update` |
| Codex เวอร์ชันเก่าเกินไป | เปิด terminal พิมพ์ `npm install -g @openai/codex@latest` |
| แพ็กของคุณใช้รุ่นนี้ไม่ได้ | เปลี่ยนรุ่นในหน้าตั้งค่า |
| โควต้าเต็ม / เกมหยุดเพราะโควต้า | รอให้รีเซ็ต หรือเลือกค่ายอื่น / ผสมหลายค่าย / ใช้รุ่นเล็กลง |
| คีย์ฟรีของ Gemini ใช้รุ่นนี้ไม่ได้ | เปลี่ยนรุ่นเป็นตระกูล Flash ในหน้าตั้งค่า · คีย์ฟรีมีโควต้ารายวันต่ำ หมดแล้วต้องรอวันถัดไป |
| คีย์ Gemini ใช้ไม่ได้ | เช็คว่าก๊อปคีย์มาครบ แล้วบันทึกใหม่ |
| AI ตอบช้าเกินไป | บางช่วงเซิร์ฟเวอร์ AI ช้าเอง ลองใหม่อีกครั้ง |
| เสียงฟรีต้องใช้ Python + edge-tts | ให้ AI ติดตั้ง Python และ `requirements.txt` ตาม `INSTALL-FOR-AI.md` |
| เสียง Gemini ต้องติดตั้ง ffmpeg | ให้ AI ติดตั้ง ffmpeg ตาม `INSTALL-FOR-AI.md` |
| เปิดเกมไม่ได้: port 7780–7789 ถูกโปรแกรมอื่นใช้อยู่หมด | ปิดโปรแกรมที่ใช้ port พวกนั้น แล้วเปิดใหม่ |
| มี Claude Code แต่เกมหาไม่เจอ | เกมหาจาก PATH, `~\.local\bin` และตัวที่มากับแอป Claude desktop ให้เองแล้ว ถ้ายังไม่เจอ ให้ใส่ที่อยู่ไฟล์ `claude.exe` ใน `data/settings.json` ตรง `"paths": { "claude": "…" }` (เพื่อความปลอดภัย หน้าเว็บตั้งค่านี้ไม่ได้) |

ข้อมูลของเราอยู่ในโฟลเดอร์ `data/` (ค่าที่ตั้ง · คีย์ · เกมที่เคยเล่น) ลบโฟลเดอร์นี้ = เริ่มใหม่หมด
